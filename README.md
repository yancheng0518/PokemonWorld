# 宝可梦：远行世界 - 开放世界RPG

## 核心设定
- 单机开放世界回合制RPG，PC优先
- 玩家扮演自创训练家，同行小智旅程（关都起步）
- 九大地区长期愿景：关都/城都/丰缘/神奥/合众/卡洛斯/阿罗拉/伽勒尔/帕底亚

## 系统要点
1. 双轨收服：丢球概率收服(参考幻兽帕鲁) + 回合制战斗收服
2. 骑乘解谜：坐骑克服地形(参考洛克王国)
3. 神兽系统：历史沉寂型(神庙召唤) + 现世活跃型
4. 画风建模：参考幻兽帕鲁

## 技术栈
- 引擎: UE 5.4 (World Partition无缝大世界)
- 建模: AI生成(Tripo3D/Meshy) → Blender清理 → UE5
- 版本控制: Git + LFS (本仓库)
