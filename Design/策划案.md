# 《宝可梦：远行世界》策划案\n\n> 项目路径：H:\\PokemonWorld　|　仓库：github.com/yancheng0518/PokemonWorld　|　更新：2024（会话总结版）\n\n## 1. 项目定位\n\n- **类型**：单机开放世界回合制 RPG，PC 优先（非商业粉丝概念案）\n- **视角**：玩家扮演自创训练家，作为同行者参与小智从关都开始的旅程；小智是主线 NPC，玩家队伍独立\n- **世界观**：九大正作地区长期愿景——关都、城都、丰缘、神奥、合众、卡洛斯、阿罗拉、伽勒尔、帕底亚\n- **主线节奏**：跟随小智旅程逐区开放，沿动画关键节点收束；完成地区主线后可自由返回旧地区\n\n## 2. 核心玩法循环\n\n探索 → 观察生态 → 收服（双轨）→ 训练/组队 → 骑乘解谜 → 道馆与剧情 → 神兽追踪 → 返回旧地区补完\n\n## 3. 三大特色系统\n\n### 3.1 双轨收服\n- **丢球直接收服**（参考幻兽帕鲁）：野外直接投掷精灵球，概率受等级/状态/距离/体型/球种/偷袭加成影响；抛物线物理判定；高等级宝可梦几乎无法直接收服\n- **回合制战斗收服**：经典属性克制/招式/特性/天气/队伍策略；道馆与训练家战固定回合制\n\n### 3.2 骑乘与地形解谜（参考洛克王国）\n- 坐骑能力门控：疾驰/攀爬/飞行/冲浪潜水/挖掘/发光等，每种能力解锁新地形与谜题\n- 谜题与环境绑定（火光照机关、水流推转轮、重物压踏板）\n- 骑乘中可丢球收服；新能力可回旧地区开新路线\n- 坐骑亲密度成长，同能力不同宝可梦手感差异化\n\n### 3.3 神兽与神庙召唤\n- **历史沉寂型**：壁画/化石/文献 → 跨地区收集证据 → 遗迹试炼（结合骑乘解谜）→ 召唤信物 → 神庙仪式 → 专属遭遇。各神兽召唤方式差异化（凤王=铃音+天气登塔；固拉多/盖欧卡=海陆异常；帝牙卢卡/帕路奇亚=时空遗迹）\n- **现世活跃型**：满足条件触发（进度/天气/图鉴等级/队伍配置等）；失败可重挑战，不永久错过\n- 收服非强制，可选择完成互动放归\n\n## 4. 视觉方向\n\n- 画风建模参考**幻兽帕鲁**：写实偏卡通、实体尺寸（体型差异明显）、饱和自然色彩、PBR 材质\n- 昼夜/天气/季节影响光照与生态\n\n## 5. 剧情结构\n\n- 每地区四段：地区旅行 → 道馆/赛事 → 地区危机（反派/遗迹）→ 神兽历史\n- 伙伴与劲敌为长期 NPC，随剧情阶段移动，可组队/委托/对战\n- 玩家可改变部分地区事件结果，但不破坏小智旅程主要节点\n\n## 6.
